# ✅ Verificação & Validação — Sum Strings as Numbers (S2/2025)

Kata focado em **testes**, **cobertura** e **técnicas de contrato**. Implementação em Java **sem BigInteger/BigDecimal**.

## 🎯 Escopo
Dado duas strings numéricas, retornar a **soma** como string.
> `sumStrings("1","2") => "3"`

## 🧪 Enfoque de Qualidade
- **ITC** (Internal Test by Contract) para detectar falhas durante a escrita dos testes  
- **ETC** (External Test by Contract) em arquivo separado para ampliar cobertura  
- Integração com **CI** e **Codecov** (badge recomendado no topo)

## ▶️ Como Executar/Analisar
Este repositório prioriza **testes** e **cobertura**, não um binário executável.
- Abra no **Codespaces** ou localmente
- Rode os **testes** (Maven/Gradle) e verifique o **relatório de cobertura**
- Consulte `tests.md` para o resumo textual dos casos
